# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security reports.

Email **security@cardz3n.com** with:

- A clear description of the issue and the component affected
- Steps to reproduce (a minimal WordPress/WooCommerce configuration is ideal)
- The impact you believe it has (data exposure, privilege escalation, payment bypass, etc.)
- Your disclosure preferences (credit / anonymous)

We will acknowledge within **2 business days** and aim to ship a fix within **14 days** for high-severity issues. We coordinate disclosure and credit responsibly.

## Scope

In scope:

- The plugin source in this repository
- The WP.org distribution zip

Out of scope:

- The upstream NMI / Network Merchants processing platform (report directly to NMI)
- Customer WordPress installs that have modified plugin code
- Generic WordPress / WooCommerce core vulnerabilities

## Safe harbor

Good-faith research following this policy will not result in legal action from CARDZ3N.
